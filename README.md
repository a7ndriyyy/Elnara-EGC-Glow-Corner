# Elnara Beauty Salon

## Про нас
Професійний салон краси в Paris. Спеціалізуємося на макіяжі, перманентному макіяжі, догляді за обличчям і тілом та апаратних процедурах. Використовуємо преміальну косметику Dior, Chanel, La Mer, Guerlain.

## Послуги
- **Макіяж**: весільний, вечірній, денний, Smokey Eyes
- **Догляд за обличчям**: чищення, RF-ліфтинг, мікротоки, масаж
- **Апаратні процедури**: вакуумний масаж, пресотерапія, карбоновий пілінг, лазерне видалення макіяжу, видалення татуювань і перманентного макіяжу
